definición
La anatomía

Solo dos ingredientes.

Toda función recursiva tiene exactamente la misma forma. Si los tienes, funciona. Si te falta uno, se rompe.

01
Caso base

La pregunta más fácil del mundo.

La que sabes responder sin pensar, sin pedir ayuda, sin llamar a nadie más. Es donde la recursión para.

02
Paso recursivo

Confía en que ya sabes resolver lo más pequeño.

Asume que la versión menor del problema ya está resuelta — y construye tu respuesta sobre ella. Sí, suena a trampa. No lo es.

Trazado de ejecución

Mira cómo crece y vuelve.

static int suma(int n) { // caso base if (n == 0) return 0; // paso recursivo return n + suma(n - 1); } suma(3); // → 6

Cada llamada espera a que la siguiente termine. Se apilan. Luego, una a una, devuelven su resultado y la pila se vacía.

suma(3) = 3 + 3 = 6
suma(2) = 2 + 1 = 3
suma(1) = 1 + 0 = 1
suma(0) = 0 ← base
Ejemplo 1 · CS61A

El Piggle.

En la primera clase de CS61A en Berkeley, Brian Harvey enseñaba este programa para enganchar a los novatos. Cabe en cinco líneas. Hace algo aparentemente difícil.

  • → Qué haceTraduce inglés a Pig Latin: "hello" → "ellohay"
  • → ReglaSi empieza por vocal, le añades "ay". Si no, mueves la primera letra al final y vuelves a intentarlo.
  • → TrucoEsa frase — vuelves a intentarlo — es recursión.
Ejemplo 1 · ejecútalo

Piggle: el mismo razonamiento, dos idiomas.

En clase ves Java. El navegador habla JavaScript, así que la versión ejecutable a la derecha es JS — pero la estructura es idéntica: una condición que es el caso base, una llamada recursiva con un argumento más simple.

Ejemplo 2 · Tsoding

¿Puede un programa imprimir su propio código fuente?

Sin leer un archivo. Sin trampa. Solo el programa, ejecutándose, escupiendo letra por letra lo que está escrito en él mismo.

Tsoding lo llama Self-Reproducing Program. La academia lo llama quine. La mejor manera de entenderlo es ver cómo se construye paso a paso.

Las siguientes 4 diapositivas son su viaje — en código que puedes ejecutar.

Paso 1 / 4 — el problema

«Sé imprimir cualquier texto. Pero ¿cuál es mi propio texto?»

Esto es Hello World. Imprime "Hola". Pero el código de Hello World no es "Hola". Si quiero que mi programa se imprima a sí mismo, el texto que sale tiene que ser exactamente este texto. Eso es justo lo que un programa normalmente no sabe sobre sí mismo.

El reto: que el código y la salida sean idénticos, carácter por carácter. Aquí ni de lejos.

Paso 2 / 4 — meter el código en una variable

«¿Y si guardo mi código en un string y lo imprimo?»

Si pongo el cuerpo del programa dentro de una cadena s y luego la imprimo, la salida será al menos parte de mi código. Pero la declaración const s = "..." también es parte de mi código, y eso no aparece en la salida. La salida es solo la mitad.

Avance: la salida contiene una línea del programa. Falta: la declaración const s = ... no aparece. Y aunque la añadiéramos a mano, tendríamos que reescribirla cada vez que cambie s. Insostenible.

Paso 3 / 4 — la revelación

«El string tiene que contener una plantilla de sí mismo.»

Espera. Si en el string dejo un hueco (una X) donde luego encajará el propio string, entonces puedo imprimir el string poniendo el string en su propio hueco. La declaración y el print salen del mismo sitio. Una sola fuente de verdad.

Casi. Al reemplazar X por s, falta una cosa: el resultado debería tener el string entre comillas, como aparece en el código original. Aquí s entra sin comillas y la salida deja de ser código JS válido.

Paso 4 / 4 — el quine

«Que la plantilla meta las comillas por mí.»

JSON.stringify(s) devuelve el string con comillas y caracteres especiales escapados — exactamente como hay que escribirlo en código fuente. Si pongo eso en el hueco, la salida es código JS válido. Y si la plantilla está bien escrita, ese código JS válido es el mismo programa.

Si te sale «✓ IDÉNTICO», acabas de construir un quine. Un programa que conoce su propio código fuente sin leerlo de ninguna parte. Bonus: copia la salida, pégala en un archivo nuevo, ejecútala. Vuelve a producir el mismo texto. Para siempre.

El mismo quine — en Java

La idea no depende del lenguaje.

JavaScript usa JSON.stringify. Java usa printf con %c y el ASCII 34 (la comilla "). C, Python, Rust: cada lenguaje tiene su variante. La plantilla siempre es la misma.

La recursión no es magia.

Es solo confianza.

Confianza en que la función que estás escribiendo ya sabe resolver el problema cuando es más pequeño. Confianza en que el string ya contiene la versión correcta de sí mismo.

DONDE LA VERÁS

Árboles del DOM. JSON anidado. Sistema de archivos. Mergesort, quicksort. Cualquier parser. Cualquier compilador.

LA RECETA

Define el caso base. Da un solo paso hacia él. La función hace el resto.

EL SOUVENIR

Tienes un quine. Cópialo y guárdalo. Es uno de los programas más bonitos que vas a escribir.
